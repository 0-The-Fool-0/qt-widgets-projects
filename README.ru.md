# Учебные проекты C++ / Qt Widgets

[English version](README.md)

Набор самостоятельных упражнений на C++ с использованием Qt. Проекты сохранены в отдельных каталогах и не объединены в одно приложение.

## Проекты

| Каталог | Что представляет |
|---|---|
| `lab1/` | Небольшой C++-проект на CMake. |
| `summer_practiceN1/` | Приложение Qt Widgets с интерфейсом телефонной книги и действиями для работы с записями. |
| `untitled6/`–`untitled9/` | Связанные упражнения по записям о лекарствах, датам и обработке текстовых/бинарных файлов. У каждого каталога свой файл проекта Qt. |
| `untitled10/` | Интерфейс Qt Widgets для данных о футбольных болельщиках и чемпионате мира: загрузка файлов, таблицы, сортировка и фильтрация. |

## Сборка и запуск

Большинство проектов используют Qt Creator/qmake через файлы `.pro`; для `lab1` используется CMake. Откройте файл соответствующего проекта в совместимом Qt Creator и собирайте его отдельно.

Некоторым лабораторным требуются входные текстовые файлы или файлы бинарных данных. Храните тестовые данные в ожидаемой рабочей директории; сгенерированные файлы запуска не входят в исходный репозиторий.

## Ограничения

Коллекция сохраняет разные учебные версии, включая незавершённые места. Например, `untitled6/med_io.h` остаётся пустым заголовочным файлом. Полная сборка и запуск всех приложений не проверялись.
